## ✅ Puntos Fuertes de Sinfonía Biótica para Destacar

- [ ] **Innovación tecnológica:** VR + biodata + Arduino
- [ ] **Sostenibilidad:** Conexión directa con naturaleza y ecología
- [ ] **Educativo:** Sensibilización sobre importancia de bosques/biodiversidad
- [ ] **Experiencial:** Inmersivo, interactivo
- [ ] **Multidisciplinar:** Arte + ciencia + tecnología + música
- [ ] **Adaptable:** Puede instalarse en diferentes espacios
- [ ] **Diálogo cultural:** Posibilidad de usar biodiversidad portuguesa
- [ ] **ODS:** Alineado con objetivos de desarrollo sostenible
- [ ] **Contemporáneo:** Uso de tecnologías emergentes
- [ ] **Universal:** Mensaje comprensible más allá del idioma
