### Información del Taller

✦ **Capturar señales bioeléctricas** de plantas con biosensores  
✦ **Digitalizar objetos y espacios** mediante fotogrametría  
✦ **Crear contenido audiovisual** en tiempo real con datos biológicos  
✦ **Explorar la creación colaborativa** entre humanos y organismos vivos

## SUGERENCIAS VISUALES PARA EL DISEÑO

### Paleta de Colores Sugerida
- **Verde orgánico** (#2D5016, #4A7C3F, #6FA85E) - Representa la naturaleza y plantas
- **Azul tecnológico** (#0A4D68, #088395, #05BFDB) - Representa tecnología y digital
- **Morado/Fucsia neón** (#B026FF, #C738BD) - Representa la intersección arte-tech
- **Blanco/Crema** (#F5F5F5, #FFFEF7) - Para texto y espacios limpios
- **Negro profundo** (#0A0E0F, #1A1D1F) - Para contraste y elegancia

### Elementos Visuales Recomendados

1. **Imágenes sugeridas:**
   - Planta con sensores conectados (cables, electrodos)
   - Visualización de ondas/señales eléctricas
   - Nube de puntos de árbol digitalizado
   - Persona con VR headset interactuando
   - Manos trabajando con tecnología y plantas simultáneamente

2. **Iconografía:**
   - 🌿 Hoja/planta estilizada
   - ⚡ Señal eléctrica/onda
   - 🎵 Onda sonora
   - 👁️ VR/headset
   - 🔬 Sensor/tecnología
   - 🎨 Paleta/creatividad

3. **Estilo visual:**
   - Fusión orgánico-tecnológico
   - Elementos naturales con overlay digital
   - Líneas limpias y modernas
   - Texturas: combinar elementos orgánicos (hojas, corteza) con elementos digitales (grids, circuitos)

### Tipografía Sugerida

**Título principal:** Fuente sans-serif moderna, bold, impactante  
Sugerencias: Montserrat Bold, Poppins Bold, Bebas Neue, Futura Bold

**Subtítulos y cuerpo:** Fuente legible, clean, contemporánea  
Sugerencias: Open Sans, Roboto, Inter, Source Sans Pro

**Detalles técnicos:** Fuente monospace para dar aspecto tech  
Sugerencias: JetBrains Mono, Courier New, Roboto Mono

## NOTAS ADICIONALES

- El diseño debe reflejar la fusión entre lo orgánico y lo tecnológico
- Usar imágenes de alta calidad que muestren tanto plantas como tecnología
- Incluir elementos que sugieran interactividad y experiencia inmersiva
- El tono debe ser accesible pero sofisticado, invitando tanto a artistas como a tecnólogos
- Destacar que no se requiere experiencia previa para generar confianza
- Si es posible, incluir testimonios o citas de participantes previos o medios

**Cita destacable para incluir:**
> "Una experiencia única en la intersección del arte, la naturaleza y la tecnología"

o

> "Cuando la tecnología amplifica las voces silenciosas de la naturaleza"
