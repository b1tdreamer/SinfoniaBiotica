# Inspiración - Proyectos Artísticos Audiovisuales sobre Comunicación Interespecie

## 🌿 **PROYECTOS SOBRE COMUNICACIÓN CON PLANTAS**

### **Plant Wave (2014-presente)**
- **Artista**: Joe Patitucci
- **Medio**: Dispositivo electrónico + App
- **Concepto**: Convierte los impulsos eléctricos de las plantas en música
- **Inspiración para SB**: Sonificación directa de datos biológicos, tecnología accesible
- **Enlace**: https://www.plantwave.com/

### **Plant Music (2015)**
- **Artista**: Mileece
- **Medio**: Instalación interactiva
- **Concepto**: Música generada por plantas conectadas a sensores
- **Inspiración para SB**: Composición musical basada en datos biológicos en tiempo real
- **Enlace**: https://mileece.com/

### **The Plant Orchestra (2018)**
- **Artista**: Mileece + colaboradores
- **Medio**: Performance en vivo
- **Concepto**: Orquesta de plantas que tocan música juntas
- **Inspiración para SB**: Colaboración entre múltiples organismos, experiencia colectiva

### **Plantas Autómatas (2019)**
- **Artista**: Gilberto Esparza
- **Medio**: Instalación robótica
- **Concepto**: Robots que se alimentan de plantas y generan sonidos
- **Inspiración para SB**: Simbiosis entre tecnología y naturaleza, autosuficiencia
